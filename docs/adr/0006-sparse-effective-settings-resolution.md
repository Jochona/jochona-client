# Effective Settings resolve sparse layers with provenance

Every Session receives one Effective Settings snapshot resolved per field from Settings Baseline, selected Streaming Profile for Client Device and Display Context, Host–Client Pair patch, Library Entry patch, Host Application patch, Session Patch/Profile Pin, Launch Adaptation, and final capability safety limits. Durable patches are sparse, application specificity wins, omitted fields inherit, and every resolved field carries value, source, reason, and pin state. A Profile Pin suppresses automatic selection/adaptation but not impossible-hardware safety; violating a Quality Floor requires pre-launch confirmation. We rejected complete snapshots because they silently freeze inherited values and make baseline changes, contextual reuse, and explainability diverge.
