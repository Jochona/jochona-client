# SQLite is authoritative for client state

Jochona uses one schema-migrated SQLite database for Settings Baselines, Streaming Profiles, Settings Patches, Controller Maps, Host and Library records, capabilities, Local History, and UI state. Secrets remain only in the operating-system Credential Vault. Existing QSettings and controller JSON are imported transactionally after a backup and then never read or dual-written again. Non-secret legacy data remains as rollback evidence. Plaintext legacy certificate and private-key values are removed only after a durable vault write is verified. We rejected permanent hybrid storage because it would make Effective Settings provenance, migrations, backups, and cross-scope consistency depend on coordinating three authorities.
