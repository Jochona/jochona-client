# Jochona Host advertises only proven Encoder Tuples

Before advertising an Encoder Tuple, Jochona Host must query the vendor encoder and successfully initialize the exact capture/display/codec/profile/bit-depth/chroma/resolution/FPS/HDR path and encode probe frames; results are cached by GPU, driver, display mode, and Host build. The first hard NVIDIA gate is AV1 Main 8-bit SDR and Main10 HDR, 4:2:0, at 3840×2160 120 fps with correct metadata, frame pacing, latency, and H.264/HEVC fallbacks; AV1 4:4:4 is separately certified. If a requested tuple fails at Session start, the Host returns a structured failure and verified alternatives—it never silently changes codec. We rejected static GPU allowlists and capability-bit-only advertisement because they repeat the false-AV1 failure that motivated first-party Host Software.
